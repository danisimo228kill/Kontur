Контур — запуск в Astra Linux

Распакуйте папку Kontur целиком в каталог пользователя.
Установите зависимости из репозиториев вашей версии Astra:

sudo apt update
sudo apt install python3 python3-pyqt5 python3-pyqt5.qtwebengine python3-pyqt5.qtwebchannel python3-serial fonts-dejavu-core ca-certificates

В каталоге Kontur выполните:
sh launch-astra.sh

Запуск в терминале для просмотра ошибок:
sh launch-astra.sh --foreground

Установка ярлыка в меню и на рабочем столе:
python3 install-shortcut.py

Карты для офлайн-режима находятся в data/regions. Для карты Яндекса
нужны интернет и ключ в config.local.json либо YANDEX_MAPS_API_KEY.
Настройки приложения сохраняются в data/map-settings.json.

USB GPS определяется автоматически. Для нестандартного имени устройства
задайте KONTUR_GNSS_PORT=/dev/ttyACM0 перед запуском. Пользователю нужен
доступ к последовательному порту, обычно через группу dialout. В VirtualBox
передайте приёмник гостевой системе через меню «Устройства → USB».
Кнопка «К GPS» центрирует карту, нажатие на точку показывает координаты.
Серая точка означает потерянное или устаревшее решение.

Для управления приводом откройте «Работа» → «Настройка ЭСП» → «Актуатор».
Стрелки ▲ и ▼ управляют направлением. Выбранный шаг в градусах меняет
только угол модели на экране.
IPv4 контроллера и UDP-порт задаются в hardware_config.py.
В режиме обмена с оборудованием нажатие «Вверх» или «Вниз» отправляет
одну UDP-датаграмму из одного байта
0x01 или 0x02 соответственно. Отпускание кнопки отправляет 0x00 (стоп).
Кнопка «Стоп» также отправляет 0x00. Код 0x03 не используется.
При уходе с вкладки или потере фокуса окном во время движения приложение
отправляет стоп на тот же адрес.
Файлы для изменения параметров

Все перечисленные файлы находятся в папке Kontur рядом с main.py.
После изменения значений перезапустите приложение.

hardware_config.py — настройки устройств и скорости:
ACTUATOR_IP, ACTUATOR_PORT — IP-адрес и UDP-порт актуатора;
ESP_IP, ESP_PORT — IP-адрес и UDP-порт ЭСП;
ESP_NEAR_PERIODS, ESP_NEAR_DEFAULT_PERIOD — периоды оборота для режима 10 км;
ESP_FAR_PERIOD — период оборота для режима 70 км;
ACTUATOR_SIMULATION_SPEED — скорость программного движения актуатора;
SIMULATION_MODE — True: работа без отправки команд; False: обмен с оборудованием;
ESP_PROTOCOL_CONFIRMED — разрешение обмена ЭСП после согласования протокола;
ESP_MOTOR_STEP_DEG — аппаратный шаг двигателя для протокола ЭСП.

esp_protocol.py — формат пакета ЭСП: PACKET, encode_command и команда stop.

drive_panel.py — команды актуатора: 0x01 вверх, 0x02 вниз, 0x00 стоп.
